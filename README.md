# Введение в нейронные сети (PyTorch)

Учебный проект по основам нейронных сетей с использованием PyTorch.  
Включает в себя работу с тензорами, создание и обучение полносвязных и сверточных нейронных сетей, а также сохранение моделей.

## Содержание

- **Часть 1: Введение в PyTorch** – тензоры, операции, срезы, автодифференцирование.
- **Часть 2: Полносвязная сеть** – создание и обучение `LinearNet` на синтетических данных.
- **Часть 3: Сверточная сеть (CNN)** – обучение `SimpleCNN` на MNIST, точность ~98.6%.

# CGCNN для предсказания свойств материалов
